## Цель работы

Изучение основ объектно-ориентированного программирования на языке Python: создание классов с использованием свойств (properties), конструкторов (`__init__`), переопределения метода `__str__` (аналог `ToString()` в C#). Отработка навыков композиции объектов, проектирования иерархий классов и модульной организации кода.

## Структура проекта

Проект организован по модульному принципу: каждый класс размещён в отдельном файле внутри пакета `models`, точка входа — `main.py`, вспомогательные функции — `utils.py`.

```
lab2_variant2/
├── main.py                        # Точка входа, демонстрация всех заданий
├── utils.py                       # Функции проверки пользовательского ввода
└── models/                        # Пакет с классами-моделями
    ├── __init__.py                # Реэкспорт всех классов для удобного импорта
    ├── name.py                    # Класс Name       (задание 1.3)
    ├── person.py                  # Класс Person     (задание 1.2)
    ├── person_with_name.py        # Класс PersonWithName (задание 2.2)
    ├── city.py                    # Классы City, CityV2  (задания 3.3, 4.8)
    └── fraction.py                # Класс Fraction   (задание 5.5)
```

Файл `__init__.py` реэкспортирует все классы, что позволяет в `main.py` использовать компактный импорт:

```python
from models import Name, Person, PersonWithName, City, CityV2, Fraction
```

## Описание заданий и решений

### Задание 1.2 — Человек

**Файл:** `models/person.py`  
**Класс:** `Person`

**Условие:** создать сущность «Человек» с именем (строка) и ростом (целое число). Текстовое представление — `"Имя, рост: N"`.

**Реализация:**

- Конструктор `__init__(self, name: str, height: int)` принимает имя и рост.
- Свойства `name` и `height` реализованы через декоратор `@property` с геттерами и сеттерами.
- Метод `__str__` возвращает строку в требуемом формате.

**Демонстрация в `main.py`:**

Создаются три объекта:

| Имя       | Рост |
|-----------|------|
| Клеопатра | 152  |
| Пушкин    | 167  |
| Владимир  | 189  |

**Фрагмент кода:**

```python
class Person:
    def __init__(self, name: str, height: int) -> None:
        self._name = name
        self._height = height

    @property
    def name(self) -> str:
        return self._name

    @name.setter
    def name(self, value: str) -> None:
        self._name = value

    def __str__(self) -> str:
        return f"{self._name}, рост: {self._height}"
```

### Задание 1.3 — Имена

**Файл:** `models/name.py`  
**Класс:** `Name`

**Условие:** создать сущность «Имя» с тремя параметрами: Фамилия, Личное имя, Отчество. Каждый параметр может быть не задан. При приведении к строке незаданные параметры пропускаются.

**Реализация:**

- Конструктор принимает три необязательных параметра со значением по умолчанию `None`.
- Типизация параметров — `str | None` (используется `from __future__ import annotations`).
- Метод `__str__` фильтрует `None`-значения и объединяет оставшиеся через пробел.

**Демонстрация:**

| Фамилия     | Имя       | Отчество   | Вывод                        |
|-------------|-----------|------------|------------------------------|
| —           | Клеопатра | —          | `Клеопатра`                  |
| Пушкин      | Александр | Сергеевич  | `Пушкин Александр Сергеевич` |
| Маяковский  | Владимир  | —          | `Маяковский Владимир`        |

**Ключевой момент:** незаданные поля (отчество у Клеопатры, отчество у Маяковского) не участвуют в формировании строки — лишних пробелов или разделителей не появляется.

**Фрагмент кода:**

```python
def __str__(self) -> str:
    parts = [
        p for p in (
            self._last_name,
            self._first_name,
            self._patronymic,
        )
        if p
    ]
    return " ".join(parts)
```

### Задание 3.3 — Города

**Файл:** `models/city.py`  
**Класс:** `City`

**Условие:** создать сущность «Город» с названием и набором путей к другим городам. Каждый путь — пара (город, стоимость). Реализовать граф городов по схеме из рис. 2.

**Реализация:**

- Конструктор принимает только название города.
- Пути хранятся в списке кортежей `list[tuple[City, int]]`.
- Метод `add_route(city, cost)` добавляет направленный путь.
- Метод `__str__` выводит название города и список связей в формате `"название: [город1:стоимость1, город2:стоимость2]"`.

**Граф из рис. 2:**

```
A → F (стоимость 1), A → B (стоимость 5)
F → B (1), F → E (6), F → C (2)
B → C (3)
E → D (2)
C → D (4)
```

**Вывод:**

```
A: [F:1, B:5]
B: [C:3]
C: [D:4]
D: нет путей
E: [D:2]
F: [B:1, E:6, C:2]
```

**Ключевой момент:** объекты `City` ссылаются друг на друга — это граф с направленными рёбрами, реализованный через взаимные ссылки объектов (рекурсивная композиция).

### Задание 4.8 — Создаём Города

**Файл:** `models/city.py`  
**Класс:** `CityV2`

**Условие:** модифицировать `City` так, чтобы город можно было создать двумя способами:
1. Указав только название.
2. Указав название и набор путей сразу в конструкторе.

**Реализация:**

- Конструктор использует `*routes` (переменное число аргументов), что позволяет передавать произвольное количество кортежей `(город, стоимость)` при создании.
- Если пути не переданы — создаётся город без связей (пустой список).
- Метод `add_route` также доступен для добавления путей после создания.

**Два способа создания:**

```python
# Способ 1: только название
city_a = CityV2("A")

# Способ 2: название + пути через конструктор
city_test = CityV2("TestCity", (city_a, 10), (city_b, 20))
```

### Задание 5.5 — Дроби

**Файл:** `models/fraction.py`  
**Класс:** `Fraction`

**Условие:** создать сущность «Дробь» с числителем и знаменателем. Дробь должна поддерживать операции сложения, вычитания, умножения и деления с другой дробью или целым числом. Результат каждой операции — новая дробь (исходные не изменяются).

**Реализация:**

- Конструктор `__init__(self, numerator: int, denominator: int)` с проверкой знаменателя на ноль.
- Автоматическое сокращение дроби при создании (метод `_reduce` использует алгоритм Евклида для НОД).
- Нормализация знака: знак всегда хранится в числителе (если знаменатель отрицателен — оба множителя меняют знак).
- Вспомогательный метод `_to_fraction` конвертирует целое число в `Fraction(n, 1)` для унифицированной арифметики.

**Арифметические методы:**

| Метод   | Операция   | Формула                                        |
|---------|------------|------------------------------------------------|
| `sum`   | Сложение   | `(a*d + b*c) / (b*d)`                          |
| `minus` | Вычитание  | `(a*d - b*c) / (b*d)`                          |
| `mul`   | Умножение  | `(a*c) / (b*d)`                                |
| `div`   | Деление    | `(a*d) / (b*c)` с проверкой деления на ноль    |

Все методы возвращают **новый** объект `Fraction`, не изменяя исходные дроби (принцип иммутабельности операций).

**Демонстрация:**

```
f1 = 1/3,  f2 = 2/3,  f3 = 3/4

1/3 + 2/3 = 1/1
2/3 - 1/3 = 1/3
1/3 * 2/3 = 2/9
1/3 / 2/3 = 1/2

1/3 + 5   = 16/3
2/3 * 3   = 2/1
```

**Цепочка вызовов:** `f1.sum(f2).div(f3).minus(5)`:

```
  1/3 + 2/3 = 1/1
  1/1 / 3/4 = 4/3
  4/3 - 5   = -11/3
```

## Вспомогательный модуль

**Файл:** `utils.py`

Содержит функции проверки пользовательского ввода:

- `input_int(prompt)` — запрашивает у пользователя целое число. В случае некорректного ввода (буквы, дробное число, пустая строка) выводит сообщение об ошибке и повторяет запрос.

## Принципы ООП, применённые в работе

### Инкапсуляция

Все атрибуты классов хранятся как приватные (с префиксом `_`). Доступ к ним предоставляется через свойства (`@property`), что позволяет контролировать чтение и запись, а в будущем — добавить валидацию без изменения внешнего интерфейса.

```python
@property
def name(self) -> str:
    return self._name

@name.setter
def name(self, value: str) -> None:
    self._name = value
```

### Композиция

Класс `PersonWithName` содержит объект `Name` как поле — это пример композиции (объект внутри объекта). Аналогично, класс `City` хранит список кортежей, содержащих ссылки на другие объекты `City`, формируя граф.

### Полиморфизм (метод `__str__`)

Каждый класс переопределяет метод `__str__`, что позволяет использовать `print(obj)` и `f"{obj}"` единообразно для любого объекта. Python автоматически вызывает `__str__` при преобразовании в строку.

### Перегрузка конструкторов

В Python нет множественных конструкторов как в C#/Java, но аналогичное поведение достигается через:

- Значения по умолчанию (`Name(last_name=None, first_name=None, patronymic=None)`)
- Переменное число аргументов (`CityV2(name, *routes)`)

## Соответствие стандарту PEP 8

Весь код проекта проверен линтером `flake8` с максимальной длиной строки 79 символов и соответствует стандарту PEP 8:

- **Длина строк** — все строки ≤ 79 символов; длинные выражения разбиты с помощью скобок.
- **Аннотации типов** — `-> None` для методов без возвращаемого значения, `str | None` для необязательных параметров, `from __future__ import annotations` для отложенного вычисления аннотаций.
- **Импорты** — отсортированы по алфавиту, сгруппированы: стандартная библиотека (`os`, `sys`) → локальные модули (`models`, `utils`).
- **Docstrings** — каждый модуль, класс и публичный метод имеет строку документации.
- **Именование** — `snake_case` для функций и переменных, `PascalCase` для классов, `_prefix` для приватных атрибутов.
- **Пустые строки** — 2 между определениями верхнего уровня, 1 между методами класса.
